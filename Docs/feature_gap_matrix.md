## 1. Назначение и правила оценки

Матрица покрывает обязательные product invariants, весь `Core Product`, все явно обозначенные P0-функции и Alpha gate из канонической спецификации. Наличие функции в Commander mode считается полезной реализационной основой, но не закрывает требование для целевого Explorer vertical slice, пока функция не проходит через целевые Registry, Store, Capabilities, OperationPlan, Error и Visual State contracts.

Статусы:

- **implemented** — поведение найдено в основном runtime path; release evidence ещё учитывается отдельно;
- **partial** — есть работающая основа, но целевой контракт, UI surface, edge states или доказательства неполны;
- **missing** — требуемый runtime contract или пользовательский сценарий в коде не найден;
- **unverified** — реализация выглядит применимой, но требуемых измерений или end-to-end evidence нет.

Milestone означает точку, в которой разрыв должен быть закрыт: M0 — baseline/evidence; M1 — source of truth и commands; M2 — local Explorer; M3 — operation lifecycle; M4 — search; M5 — power-user workflow; M6 — archives/remote; M7 — release hardening.

## 8. Critical path

Alpha нельзя закрывать накоплением новых UI surfaces поверх legacy dispatch. Критическая последовательность:

1. M0 фиксирует state ownership, mutation boundary, CI и 10k/100k baseline.
2. M1 вводит Command Registry, ProviderCapabilities, Error Model и Visual State composition; production navigation/refresh используют controller-owned lifecycle/Store path. Operations now includes typed reviewed authority, bounded Native publication, lossless result mapping, sealed execution product, private factory integration, exact retry/reconcile/release custody, restricted hooks, exact durable outcome delivery, preallocated Pool finalization and one bounded production `CopyAs` consumer. Its app proof is complete; an opt-in physical-volume fixture awaits an actual run and hardware power-loss evidence, followed by cross-volume staging and the remaining P0 roster.
3. M2 переводит один local Explorer slice целиком на эти контракты и завершает tabs/preview/persistence/states.
4. M3 переводит все P0 mutations на `OperationPlan` и persistent Operation Center.
5. M7 принимает Alpha только по автоматизированному evidence из этой матрицы.

Добавление новых remote, archive или expert surfaces до стабилизации этого пути увеличит число несовместимых entry points и стоимость миграции.
