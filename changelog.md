# Changelog

This file records completed development work in the Win Commander fork. Product release notes remain in `WHATS_NEW.md`.

## Unreleased

### Added

- Added an Explorer mode that hosts a single existing file panel over the shared VFS and file-operation infrastructure and can be entered from Commander mode.
- Added Explorer navigation chrome with Back, Forward, Up, Refresh, breadcrumbs, editable path entry, Find Files entry, and `Command-L` address focus.
- Added an Explorer sidebar backed by existing favorites, mounted volumes, saved network connections, and tags.
- Added an Explorer command bar for creating items and invoking selection-aware Cut, Copy, Paste, Rename, Share, Trash, Sort, View, and More actions; several View/More surfaces remain intentionally incomplete.
- Added Explorer quick-search presentation with match count and clear/cancel behavior.
- Added Explorer-specific list presentation and layout storage so Explorer column configuration is independent from Commander layouts.
- Added list grouping/projection support and panel presentation geometry coverage used by the evolving Explorer layout.
- Added stable local-development build/sign/install tooling and a dedicated development entitlement/configuration path.
- Added Win Commander application artwork and icon assets.

### Changed

- Rebranded the application, source tree, Xcode project, schemes, bundle identifiers, scripts, resources, and documentation from Nimble Commander to Win Commander while preserving upstream GPLv3 notices.
- Extended shared panel actions and pasteboard handling for Explorer-style Cut/Copy/Paste behavior, including visible cut state and cancellation.
- Updated file-panel list, brief, gallery, header, footer, selection, and geometry behavior to support the Explorer presentation without replacing the existing panel engine.
- Updated network-connection and tag storage interfaces used by the Explorer sidebar.
